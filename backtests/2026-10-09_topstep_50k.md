# Topstep 50K modelled on real published rules — 2026-10-09

**Verdict:** EV-positive under the modelled rules, with a thin margin and significant unmodelled risk.

## Rules used (checked 2026-10-09)

| | |
|---|---|
| Start / target | $50,000 / +$3,000 |
| Maximum Loss Limit | $2,000, trails from **end-of-day balance only**, never moves down, **locks at the starting balance** |
| Breach check | real time, including open P&L |
| Daily Loss Limit | $1,000, optional — **hitting it is a lockout for the day, not a failure** |
| Consistency | best day ≤ 50% of target ($1,500); exceeding raises the target to best_day/0.5 rather than failing |
| Fees | **$49/month + $149 activation** (Standard Path) |
| Funded (XFA) | DD starts $2,000 below, locks at breakeven; 90/10 split; payout needs 5 winning days ≥ $150 |

Sources: [futureshive](https://www.futureshive.com/blog/topstep-rules-explained), [propdatalab](https://propdatalab.com/firms/topstep/), [propfirmaudit](https://propfirmaudit.com/education/topstep-rules-explained-2026), [tradecovex](https://tradecovex.com/guides/topstep-combine-rules-2026). Third-party blogs can conflict and rules change — verify on Topstep's own site before paying.

## Strategy input
Coin-flip entries (no edge), 3×ATR stop (~214 NQ points), target at half the stop (0.5:1).
Measured on real hourly NQ: 5,132 trades, 55.5% win rate, **−0.027R expectancy**.

## Results

|---|---|---|---|---|---|
| 0.5% | $250 | 1.2% | 94 | $0 | −$247 |
| 1.0% | $500 | 13.0% | 60 | $1,037 | −$32 |
| 1.5% | $750 | 19.0% | 33 | $1,052 | +$74 |
| 2.0% | $1,000 | 21.6% | 20 | $1,029 | +$141 |
| **3.0%** | **$1,500** | **26.9%** | **11** | **$1,120** | **+$212** |
| 4.0% | $2,000 | 26.2% | 6 | $1,018 | +$178 |

Low risk loses because the $49/month subscription runs for months while you grind; high risk loses
because one full stop approaches the $2,000 MLL. The optimum is where passing takes ~2 weeks.

## Sensitivity — the number that matters

| True edge | Pass | EV |
|---|---|---|
| −0.016R (coin flip, 3×ATR) | 29.2% | +$259 |
| −0.027R (**measured input**) | 26.8% | +$210 |
| −0.050R | 21.5% | +$122 |
| −0.080R (coin flip at 1×ATR) | 15.8% | +$46 |
| **−0.120R** | 9.3% | **−$13** |
| −0.160R | 4.9% | −$38 |

**Break-even is about −0.12R.** The measured input is −0.027R, so there is roughly 4× headroom —
but only if live execution resembles the simulation. Using tight stops alone (−0.078R) cuts EV to +$46.

## Issues
1. **Not modelled, all EV-reducing:** the funded Scaling Plan's position limits, payout caps and
   waiting periods, reset fees, and slippage worse than 1 tick.
2. 3% risk means a full stop is 75% of the entire MLL. Two bad days ends the account. The high EV
   depends on passing fast enough to pay only one month's subscription.
3. The −0.027R input carries its own uncertainty (roughly ±0.02R), which moves EV by ~±$90.
4. 73% of attempts still fail; this is a repeated game.

## Next action
Paper trade the exact spec (3×ATR stop, 0.5:1 target, 3% risk, 1 trade/day) for 4–8 weeks and
measure the realised per-trade R. If it lands above −0.08R, the model holds. If it lands near
−0.12R, stop.
